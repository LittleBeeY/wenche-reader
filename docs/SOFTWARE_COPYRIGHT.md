申请表、源程序、用户手册、软件界面和发布包应保持上述名称及版本一致。申请人、开发完成日期、首次发表日期和权利取得方式由著作权人根据真实情况填写，不在代码仓库中预设。

## 冻结规则

- 以 Git 标签 `v1.0.0` 对应提交作为材料基线。
- 软著源程序只选取项目原创代码，不包含 `node_modules/`、第三方库、用户数据和密钥。
- 用户操作手册使用 V1.0 实际界面截图，覆盖安装、导入、归档、阅读、划词解析、AI 配置和删除流程。
- 提交申请后，新功能进入后续版本，不覆盖 V1.0 鉴别材料。
